# 78 项 Agent 技术方向清单

这是一份需求与开发阶段的**检查清单**，不是任何项目已接入全部技术的声明。使用需求确认 Skill 时，可把本文件与过往 PRD 一同提供，要求将每项方向标为“必接 / 后续 / 仅选型 / 不适用”，并写明业务理由。具体技术选型、实现与运行证据由开发阶段核对。

原始清单中 `A09` 的内部编码没有定义，应保持“待确认”，不能推测含义。不同业务项目可以采用不同阶段和技术取舍。
