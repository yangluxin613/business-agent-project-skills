# 业务 Agent 项目 Skill 使用说明

这是一个包含三种模式的 Skill。主入口是 `SKILL.md`；`references/requirements/`、`references/development/`、`references/interview/` 分别保存三个阶段的细则。导入时保留整个目录和相对路径。

| 想做的事 | 对话中怎么说 | 本轮停在哪里 |
|---|---|---|
| 从旧项目经历确认新 Agent 需求 | `使用 business-agent-project 的需求模式，先做 P00—P02，给我不同业务任务的候选项目。` | 候选比较；P03、P04 由你分别审阅确认 |
| 根据已确认需求开发 | `使用 business-agent-project 的开发模式，核对 P03/P04，只做 P05，先写技术覆盖与架构。` | P05；后续每次指定一个开发单元并验收 |
| 根据现有项目准备面试 | `使用 business-agent-project 的面试模式，先核对项目证据，只做 P14A—B。` | 事实台账与项目叙事；不自动补开发 |

也可明确说“用这个 Skill 跑完整流程”。此时仍需分别确认 P03 选题和 P04 场景；每个开发单元先写验收卡，再实际测试和复测。使用模拟 PRD 时，将模拟确认、合成测试与真实项目状态分开记录。

如果此前使用过其他版本，可以继续使用项目工作区中的 `project-state.md`、需求包和验收证据，避免重做已经确认或通过的工作。
