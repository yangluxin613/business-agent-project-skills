# 外部系统集成与平台封装（P11A）

P11A1 与 P11A2 可分别交付。先列真实资料、权限、设备和部署条件；没有接口文档时只定义适配契约与明确标记的 Mock，不补造供应商地址、报文、认证方式或成功率。

## P11A1：业务系统对接

逐系统列权威字段、身份、时效、事件、失败、重试、幂等和对账。Mock 应能演示成功、超时、重复、乱序、权限失败与恢复，并列出真实接口替换条件。对真实系统有权限才联调，记录具体接口版本与原始结果。分别验收业务闭环、故障后对账、重复事件和跨角色权限；Mock 通过只证明适配层行为，不证明医院/客户真实系统已对接。

## P11A2：平台与租户隔离

将可复用业务能力封装为 API/SDK，明确业务产品与公共平台职责。多租户隔离账号、知识、Skill、模型、工具、记忆、任务、用量与审计；MCP 平台共用 Tool/Resource/Prompt 注册、发现、版本、健康、权限和日志。根据资源条件设计或实现管理控制台、凭证轮换、密钥存储、内部网络隔离、离线支持、升级/回滚。至少验证跨组织越权、API/SDK 闭环、凭证失效和旧业务回归；私有化部署缺条件时只写部署/验收前提，不标为已运行。

输出接口契约、Mock/真实路径状态、API/SDK 示例、隔离证据、验收卡与 P11A 实施记录。
