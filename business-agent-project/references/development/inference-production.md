# 推理路径与运行工程（P11B）

将“当前可控调用链”和“供应商或未来私有引擎内部能力”分开。没有 GPU、真实流量或私有模型时仍可完成选型，但不能写 GPU 吞吐、KV Cache 或生产 P95 已实测。

## P11B1：选型

盘点模型类型、质量/延迟目标、并发、数据安全、GPU/CPU、预算与运维能力。比较现有兼容 API、vLLM、TGI、Triton 的支持模型、资源、并发/吞吐、延迟、运维复杂度及替换条件；选择当前可验证路径。KV Cache 与连续批处理若由供应商控制，只标“供应商内部/未验证”；不要靠远程 API 调用推断其运行。

## P11B2：实际调用链与生产保障

对可控层设计并按需要接入 Prompt/授权结果缓存、流式、请求合并、并发/超时、限流、降级、模型路由、Token 预算。缓存列键、权限隔离、TTL、失效和敏感数据规则；审批结果不得绕过新鲜度检查。补日志、指标、Trace、脱敏、Prompt/Skill/模型/知识版本、健康、灰度/A-B、备份与恢复；仅实现有资源验证的部分。

每项实际接入的能力先测正确性、隔离、失效和旧流程回归，再记录延迟/成本差异。给低成本、平衡、高质量三档方案与推荐前提，所有数据附样本量、环境、时间和测量方法。输出选型、性能记录、恢复/回滚演练、验收卡与 P11B 实施记录；缺生产资源列待实测清单。
