# 模型、Prompt、Tool Use 与业务 Skill（P10A）

按已确认的业务结果契约接入模型；涉及写入时对接业务状态机。不能用 Prompt 替代权限、来源版本或已要求的人工决策。若用户只要求某一子能力，实施该子能力及直接依赖，不自动接入全部模型栈。

## P10A1：模型客户端与 Prompt

先确认可用服务、模型名、预算、敏感数据边界与本地凭证方式。客户端记录配置、超时、重试、错误、Token 和角色路由；密钥不写入代码、日志或文档。System/Task/Tool/Knowledge Prompt 分层并固定版本；Few-shot 只有在比较样例证明确有价值时才保留。模型输入按授权事实投影，输出结构化草稿与可审计步骤摘要，不要求私有 CoT。

区分模板路径与真实模型路径。用合成业务样例实际调用已配置模型时，记录模型身份、请求数、Token、延迟、草稿校验与失败轨迹。无密钥可完成离线实现，但真实调用标“待验收”。先验证草稿内容、低置信度、错误和旧业务回归，再接入依赖模型输出的下一子单元。

## P10A2：受控工具循环与 Skill

Tool Schema 明确参数、返回、权限、错误，以及写入工具的幂等条件；宿主固定用户/组织身份，重验模型提出的每个行动键、来源版本、引用与业务合法动作。多轮 Function Calling 设置步数/Token/耗时预算、停止条件与失败关闭。写操作遵守已确认业务规则要求的授权和人工审核门禁。

Skill 注册表至少含名称、用途、元数据、组织/角色、依赖、允许工具、版本、停用与失败规则；设计至少五个贴合业务的 Skill 示例，实际接入范围按阶段目标。用业务对话消息触发 Skill 选择，记录选择依据、版本、工具结果如何改变回复或待审草稿，以及未匹配/越权时的对话表现。阶段测试包括正确选择、额外参数拒绝、越权拒绝、重复调用/超预算终止、工具失败、旧流程回归和前端可见结果。输出代码、配置、调用轨迹、验收卡及 P10A 实施记录；只把实际运行的模型/Skill 标为已接入。
